# LinkHarvest

[English](../README.md) | 中文 | [Español](README_es.md) | [Deutsch](README_de.md) | [日本語](README_ja.md) | [Français](README_fr.md)

一款轻量级浏览器扩展，可从任意网页提取全部超链接，支持智能筛选与 CSV 导出。

> 基于 Chromium · Manifest V3 · 无追踪 · 数据仅存本地

---

## 功能特性

| 功能 | 说明 |
|------|------|
| 🔍 **一键扫描** | 提取当前页面所有 `<a>` 标签链接 |
| 📡 **实时 DOM 监听** | MutationObserver 捕获动态新增链接（SPA、无限滚动） |
| 🔎 **智能筛选** | 过滤锚点链接、JavaScript 伪链接；区分站内/站外 |
| 📋 **批量复制** | 一键复制所有有效链接到剪贴板 |
| 📥 **CSV 导出** | UTF-8 BOM 编码，兼容 Excel/WPS |
| 🔒 **数据仅存本地** | 所有数据仅保存在浏览器内存中，关闭页面即清空 |
| 🌍 **多语言** | 支持中文、英文、日文、德文、西班牙文、法文 |
| ⚡ **轻量** | 纯原生 JavaScript，零依赖，包体 < 40KB |
| 🏗️ **Manifest V3** | 仅需 `activeTab` + `scripting` 最小权限 |

## 安装

1. 打开浏览器扩展页面：
   - **Chrome**：`chrome://extensions/`
   - **Edge**：`edge://extensions/`
2. 开启**开发者模式**（右上角开关）
3. 点击**加载已解压的扩展程序**，选择项目文件夹
4. 点击工具栏中的 LinkHarvest 图标即可开始

---

## 使用方法

1. **打开目标网页**，等待动态内容加载完成
2. **点击工具栏中的 LinkHarvest 图标**
3. **开启 DOM 监听**（可选）— 适用于无限滚动或延迟加载链接的页面
4. **点击「扫描当前页面链接」** — 即时提取所有链接
5. **查看完整列表** — 打开独立结果页面，表格形式展示
6. **搜索与筛选** — 使用搜索框和筛选开关精简结果
7. **复制或导出** — 复制链接到剪贴板或导出为 CSV 文件

> **⚠️ CSV 导出风险提示：** 导出的 CSV 文件将保存至您的设备本地磁盘。该文件由您自主管理，插件不控制本地导出文件的生命周期。如不再需要，请手动删除导出文件。

## 采集字段

| 字段 | 说明 |
|------|------|
| `linkText` | 链接显示文本（已清洗） |
| `href` | 完整绝对 URL |
| `target` | `_blank` / `_self` |
| `category` | 锚点 / JavaScript 伪链接 / 协议链接 / 普通链接 |
| `isInternal` | 是否为同源站内链接 |

## 隐私

- 仅需 `activeTab` + `scripting` 权限，不做额外请求
- `activeTab`：仅在用户主动点击扩展图标时获取当前标签页临时访问权限
- `scripting`：用于向当前页面注入链接采集脚本
- 不使用 `<all_urls>` 权限，不会在未经操作的情况下访问任何页面
- 不发起外部网络请求，所有处理在本地完成
- 不访问浏览历史，不追踪用户，不上传数据
- 所有扫描数据仅保存在浏览器内存中，关闭页面后自动清除
- [Privacy Policy](../privacy-policy.html)

### 未申请的权限

| 权限 | 不申请原因 |
|------|-----------|
| `<all_urls>` | 不会在未经用户操作的情况下访问页面 |
| `storage`（持久化）| 不会将数据写入本地持久存储 |
| `notifications` | 不发送系统通知 |
| `cookies` | 不读取或修改 Cookie |
| `webRequest` | 不拦截或监听网络请求 |

### 不采集的数据

- ❌ 页面密码、表单输入内容
- ❌ Cookie、LocalStorage、IndexedDB、SessionStorage 数据
- ❌ 浏览器缓存、浏览历史
- ❌ 用户身份凭证、登录信息
- ❌ 页面正文文本、图片、视频等媒体内容
- ❌ 第三方脚本数据、广告追踪信息
- ❌ 设备标识符、IP 地址、用户行为数据

### 用户权利（GDPR/CCPA 合规）

- **停止权**：您可随时关闭插件或停止扫描操作
- **删除权**：关闭页面或浏览器后，所有内存数据自动清除；您也可随时手动删除本地导出的 CSV 文件
- **查阅权**：本插件不存储任何可识别用户身份的数据，无可供查阅的用户数据
- **数据可携权**：CSV 导出功能已支持数据导出
- **退出权**：本插件不涉及任何数据追踪或画像行为，无需额外退出操作
