LinkHarvest Privacy Policy

Short version: Scans, filters and exports run entirely on your device. LinkHarvest makes network requests only in two cases you control: (1) Link Audit sends HTTP HEAD/GET requests directly to the links you choose to check — no page content or scan results are uploaded; (2) optional Premium license activation sends a minimal install identifier to the license server. If you never run an audit or activate a license, the extension makes no network requests.

01Data Collection

LinkHarvest does not collect any personal data:

  • Browsing history or URLs visited
  • Page content, images, or text
  • Cookies or tracking identifiers
  • Usage analytics or telemetry

02Permissions

LinkHarvest requests minimal permissions:

  • activeTab — Grants access only when you click the extension icon
  • scripting — Used to inject the link collection script on user-triggered scan
  • storage — Stores scan results temporarily for the results page; cleared when the scanned tab is closed
  • contextMenus — Adds a right-click "Extract page links" menu item; reads no data itself
  • Optional site access — Requested only when you start Link Audit; lets the results page send HTTP HEAD/GET requests to the links being checked (cookies are not sent)
License verification connects to api.annmax1983.com only when you activate a paid license. Link Audit connects directly to the target URLs only when you start it. No other network requests are made.

03Third-Party Services

License Verification (Premium): If you activate a premium license, LinkHarvest contacts our license server at api.annmax1983.com directly; Creem only handles the payment. The request includes: license key, a random install identifier, plugin identifier, and browser metadata. Link Audit: When you start an audit, the results page sends HTTP HEAD/GET requests directly from your browser to each checked URL (follows redirects, no cookies). Those websites may see your IP address and request metadata under their own privacy policies. Audit results stay in your browser and are never sent to us or any third party. Our license server records the IP address of these requests solely for rate limiting and abuse prevention — never for profiling, advertising, or sharing with third parties.

04Data Storage

Scan results are stored in chrome.storage.session temporarily and cleared when the scanned tab is closed. Link Audit results are kept in memory on the results page only and disappear when you close that page or rescan. License data is stored locally; if the server cannot be reached, the cached license keeps working until the next successful check. Saved filter presets and UI preferences are kept in this browser's localStorage; they never leave your device and can be cleared at any time. All data is deleted when you uninstall the extension. Our license server records the IP address of these requests solely for rate limiting and abuse prevention — never for profiling, advertising, or sharing with third parties.

05Data retention & deletion

Your settings and content stay in your browser until you delete them in the extension or uninstall it. Uninstalling removes the extension's local data. Nothing is retained on our servers, because your content is never sent to them.

06Changes to this policy

If this policy changes, the revised version will be published on this page with a new date. Material changes will be noted in the extension's release notes.
