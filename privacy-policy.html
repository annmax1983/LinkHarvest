🔗 LinkHarvest Privacy Policy

Last updated: July 2026

1. Data Collection Statement

LinkHarvest does not collect, store, or transmit any user data to external servers.

Core Principle: All data processing is performed locally within the browser, with no remote server communication.

2. How It Works

  • Only reads hyperlinks (<a> tags) on the current page when you actively click the "Scan" button
  • All collected data is temporarily stored in browser memory (chrome.storage.session)
  • All data is automatically cleared when you close the results page or browser
  • Does not use persistent storage (such as chrome.storage.local) to save user data

3. Permissions

  • activeTab: Only grants temporary access to the current tab when you actively click the extension icon; does not have persistent access
  • scripting: Used to inject the link collection script into the current page; only executes when you trigger a scan

We do not request the following permissions:

  • ❌ <all_urls> — Will not access any page without your consent
  • ❌ storage (persistent) — Will not write data to local persistent storage
  • ❌ notifications — Does not send system notifications
  • ❌ cookies — Does not read or modify cookies
  • ❌ webRequest — Does not intercept or monitor network requests

4. Data Collection Scope

✅ What We Collect

  • Publicly rendered <a> hyperlink tags on the page
  • Link display text, URL, and target attribute
  • Link classification (internal/external/anchor/protocol)

❌ What We Do NOT Collect

  • Passwords or form input content
  • Cookies, LocalStorage, IndexedDB, or SessionStorage data
  • Browser cache or browsing history
  • User credentials or login information
  • Page body text, images, videos, or other media content
  • Third-party script data or advertising tracking information
  • Device identifiers, IP addresses, or user behavior data

5. Real-Time DOM Monitoring

This extension offers an optional "Real-Time DOM Monitor" feature:

  • This feature is disabled by default and must be manually enabled by the user
  • When enabled, uses MutationObserver to monitor DOM changes and capture dynamically loaded new links
  • Monitoring scope is limited to newly added <a> tags; does not read other DOM changes
  • It is recommended to disable this feature after collection is complete to reduce unnecessary resource usage
  • Monitored data is also only stored in browser memory and cleared when the page closes

6. CSV Export Notice

⚠️ Local File Risk Notice: Exported CSV files will be saved to your local device disk. These files are managed by you; the extension does not control the lifecycle of local exported files. Please manually delete exported files when no longer needed.

7. Network Requests

LinkHarvest does not make any external network requests. All features run entirely locally, with no communication with any remote servers.

8. Third-Party Services

LinkHarvest does not integrate any third-party analytics, advertising, tracking, or SDK services.

9. User Rights (GDPR/CCPA Compliance)

  • Right to Stop: You can close the extension or stop scanning at any time
  • Right to Delete: All memory data is automatically cleared when you close the page or browser; you can also manually delete locally exported CSV files at any time
  • Right to Access: This extension does not store any personally identifiable user data; there is no user data to access
  • Right to Data Portability: CSV export functionality supports data export
  • Right to Opt-Out: This extension does not involve any data tracking or profiling; no additional opt-out action is needed
